      YouTube cookies

      YouTube blocks servers unless they send the cookies of a signed-in browser.

      1. A browser running on this server opens in a new tab. Sign in to YouTube there. A spare Google account is safest: YouTube can flag accounts that are used for downloading.
      2. mixgrab takes the YouTube cookies from that browser and keeps them fresh for as long as it stays signed in.
      Upload a cookie file instead
      1. Firefox (easiest). Sign in to youtube.com in Firefox, then close Firefox. Upload this file from your Firefox profile folder:
        In the file dialog, paste the folder into the address bar, open your profile folder (xxxxxxxx.default-release) and choose cookies.sqlite. Only the YouTube cookies are kept; the rest of the file is discarded.
      2. mixgrab app on your computer. Run mixgrab --export-cookies, then upload the file it prints, .
      3. Any browser. Export cookies.txt with an extension such as Get cookies.txt LOCALLY and upload it.

      Chrome and Edge encrypt their cookie file, so it can't be uploaded directly. Use option 2 or 3 for them.
